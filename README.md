# Botik

iOS-клиент для нейросетей в стиле ChatGPT/Claude, рассчитанный на модели без цензуры
(например `huihui_ai/*-abliterated`), но работающий с любым OpenAI-совместимым API.

## Возможности

- Стриминг ответов, кнопка «Стоп», «Повторить», редактирование и переотправка сообщений
- **Размышления**: показываются отдельным сворачиваемым блоком «Думает… / Думал N с».
  Поддерживаются поля `reasoning_content` (DeepSeek, vLLM), `reasoning` (Ollama, OpenRouter),
  `thinking`, а также теги `<think>…</think>` прямо в тексте (Qwen3, R1 и т.п.)
- **Картинки**: из галереи (до 10 за раз), с камеры, из буфера обмена; отправляются как `image_url`
  (base64) — работает с vision-моделями (gemma3, qwen2.5-vl, llava…). Просмотр с зумом, сохранение в Фото
- **Файлы**: PDF (извлекается текст), любые текстовые файлы и код (txt, md, json, csv, py, swift…);
  длинный текст из буфера автоматически становится файлом. Просмотр через Quick Look
- **Markdown**: заголовки, списки, чек-листы, цитаты, таблицы, блоки кода с кнопками
  «Копировать» и «Сохранить как файл»
- Несколько серверов, выбор модели прямо в чате, загрузка списка моделей с сервера
- Общий и отдельный для каждого чата системный промпт, температура, лимит токенов, длина контекста,
  произвольные доп. параметры запроса в JSON
- Поиск по чатам, переименование, экспорт чата в Markdown, iPad (сплит-экран)

## Где взять IPA

Каждый пуш собирается в GitHub Actions (`.github/workflows/build-ipa.yml`) на macOS.
Готовый `Botik.ipa` лежит в **Releases** (для ветки `master`) и в артефактах запуска Actions.

IPA не подписан. Установить можно через:
- **Sideloadly** / **AltStore** / **SideStore** — подпишут вашим Apple ID (бесплатный аккаунт — 7 дней);
- **TrollStore** — навсегда, если ваша версия iOS поддерживается.

## Подключение нейросети

### На своём VPS (одна команда)

На Ubuntu/Debian под root:

```bash
curl -fsSL https://raw.githubusercontent.com/wyrtex/botik/master/server/setup.sh | sudo DOMAIN=ai.example.com bash
```

Скрипт ставит Ollama, скачивает `huihui_ai/qwen3-abliterated` (размер по объёму RAM)
и закрывает доступ ключом через прокси Caddy с бесплатным HTTPS-сертификатом.
Перед запуском добавьте в DNS домена A-запись на IP сервера. Без домена: `sudo PORT=8080 bash` (обычный http). В конце печатает адрес,
API-ключ и модель — их надо вписать в приложении (Настройки → Добавить сервер → Свой).
Свою модель или порт можно задать так: `... | sudo MODEL=huihui_ai/qwen3-abliterated:14b PORT=9000 bash`.

### Ollama на компьютере (локально, без цензуры)

```bash
ollama pull huihui_ai/qwen3-abliterated:8b        # текст + размышления
ollama pull huihui_ai/gemma3-abliterated:12b      # понимает картинки
OLLAMA_HOST=0.0.0.0 ollama serve                  # чтобы телефон видел сервер по Wi-Fi
```

В приложении: Настройки → Добавить сервер → Ollama → адрес `http://<IP компьютера>:11434/v1`
→ «Загрузить список моделей». Телефон и компьютер должны быть в одной сети
(или используйте Tailscale / ngrok для доступа извне).

### Облако

OpenRouter: адрес `https://openrouter.ai/api/v1` + API-ключ. Подойдёт любой другой
OpenAI-совместимый сервис (Together, Groq, DeepInfra, свой vLLM и т.д.).

## Сборка вручную (на Mac)

```bash
brew install xcodegen
xcodegen generate
open Botik.xcodeproj
```

Требуется Xcode 16+, iOS 17+.
